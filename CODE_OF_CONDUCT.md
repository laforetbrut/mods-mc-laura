# Code of Conduct

My Girlfriend Laura (mod id `lauramod`), author / auteur : vyrriox.

- [English](#code-of-conduct)
- [Français](#code-de-conduite)

## Our pledge

We want this project to be a friendly place for everyone, regardless of age, body size, disability,
ethnicity, gender identity and expression, level of experience, nationality, appearance, religion
or sexual orientation.

## Expected behavior

- Be respectful and welcoming.
- Accept constructive criticism.
- Focus on what is best for the community.

## Unacceptable behavior

- Harassment, insults or personal attacks.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may remove, edit or reject contributions that do not follow this code, and may ban
contributors temporarily or permanently.

Reports go through GitHub, never by email:

- In private, through a
  [GitHub private advisory](https://github.com/laforetbrut/mods-mc-laura/security/advisories/new) on
  the repository. Only you and the maintainers can read it.
- On the content itself, with the report entry in the menu of the comment, issue, discussion or
  pull request (GitHub's moderation tools).

Please do not answer the problem in public and do not copy private information into a report.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

# Code de conduite

## Notre engagement

Nous voulons que ce projet soit un lieu accueillant pour tout le monde, quels que soient l'âge, la
corpulence, le handicap, l'origine ethnique, l'identité et l'expression de genre, le niveau
d'expérience, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Comportement attendu

- Être respectueux et accueillant.
- Accepter les critiques constructives.
- Se concentrer sur ce qui est le mieux pour la communauté.

## Comportement inacceptable

- Le harcèlement, les insultes ou les attaques personnelles.
- La publication d'informations privées d'autrui sans autorisation.
- Toute conduite qui serait déplacée dans un cadre professionnel.

## Application

Les mainteneurs peuvent retirer, modifier ou refuser les contributions qui ne respectent pas ce
code, et bannir des contributeurs de façon temporaire ou définitive.

Les signalements passent par GitHub, jamais par e-mail :

- En privé, via une
  [advisory privée GitHub](https://github.com/laforetbrut/mods-mc-laura/security/advisories/new) sur
  le dépôt. Seuls vous et les mainteneurs pouvez la lire.
- Sur le contenu lui-même, avec l'entrée de signalement du menu du commentaire, de l'issue, de la
  discussion ou de la pull request (outils de modération de GitHub).

Merci de ne pas répondre au problème en public et de ne pas recopier d'informations privées dans
un signalement.

Ce code est adapté du [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
